# Судоку

Минималистичное судоку в браузере: https://ptsilko.github.io/web-sudoku/

- 4 уровня сложности: Лёгкий, Средний, Сложный, Эксперт
- каждая головоломка генерируется заново и имеет единственное решение
- заметки, отмена, подсказки, счётчик ошибок, таймер, рекорды
- прогресс сохраняется в браузере
- светлая и тёмная тема, удобно на телефоне

## Управление с клавиатуры

| Клавиша | Действие |
| --- | --- |
| `1`–`9` | поставить цифру |
| `Backspace` / `Delete` / `0` | стереть |
| стрелки | перемещение по полю |
| `N` | режим заметок |
| `H` | подсказка |
| `Ctrl+Z` | отменить |

## Разработка

Статический сайт без сборки — файлы лежат в `public/`. Открыть `public/index.html` в браузере.

Тесты генератора: `node tests/sudoku.test.js`

При пуше в `main` GitHub Actions прогоняет тесты и публикует `public/` в ветку `gh-pages`,
откуда сайт раздаёт GitHub Pages.
